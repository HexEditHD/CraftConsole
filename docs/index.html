Features

Everything you need to run
a Minecraft server

A complete HMI-style control panel for your server — from console output to player management, all in one app.

📊
Live Dashboard
Real-time machine CPU & RAM, server process metrics, player count, memory usage, and uptime — displayed with arc gauges and gradient progress bars.
⬛
Server Console
Colour-coded log stream with level filtering (INFO / WARN / ERROR), player avatar chips, and a command input bar.
👥
Player Management
See online players, view stats, kick or ban with a reason dialog, manage the whitelist and ban list in real time.
⚙️
Server Control
Start, stop, and restart the server. Select JAR file, configure JVM arguments, and manage your server profile settings.
📁
Config Editor
Browse and edit any file in your server directory with a built-in text editor. No need to leave the app to tweak server.properties.
🔍
Issue Tracker
Automatically surfaces WARN and ERROR log entries into a dedicated issue panel, making it easy to spot and diagnose problems.
